# Typing Game

ブラウザ上で遊べる、対戦演出付きのタイピングゲームです。  
Djangoをバックエンドに、Canvas APIとJavaScriptを使ってゲーム画面・入力判定・スコア表示・レート管理を実装しています。

## 概要

この作品は、単純なタイピング練習ではなく「対戦している感覚」を持って継続的に遊べることを意識して制作しました。  
プレイヤー名を入力すると、スコアやレートを保存し、次回以降のプレイにも結果が反映されます。

就職活動用のポートフォリオとして、以下の点を伝えることを目的にしています。

- Webアプリケーションの基本構成を理解し、自分で実装できること
- フロントエンドのゲーム処理とバックエンドのデータ保存を連携できること
- ユーザー体験を考え、画面演出・音声・レートなどの要素を組み込めること
- 既存機能を分解し、改善しながら開発を進められること

## 主な機能

- **タイピングゲーム機能**  
  表示された文章を入力し、正しく入力できた文章数をスコアとして扱います。

- **日本語・英語モード切り替え**  
  画面上のラジオボタンから、日本語モードと英語モードを選択できます。

- **疑似対戦演出**  
  CPU対戦相手を表示し、マッチング画面・カウントダウン・勝敗表示など、ゲームらしい流れを実装しています。

- **レート管理機能**  
  プレイヤーの勝敗に応じてレートを計算し、Django側で保存・取得します。

- **ハイスコア管理**  
  プレイヤー名ごとのスコアを保存し、過去の成績を参照できる構成にしています。

- **Canvasによる画面描画**  
  キャラクター、背景、スコア表示、結果画面などをCanvas上に描画しています。

- **BGM切り替え**  
  ボタン操作でBGMのON/OFFを切り替えられます。

## 実装で工夫した点

### 1. ゲーム進行をフェーズで管理

タイトル画面、マッチング画面、カウントダウン、タイピング、結果画面をフェーズとして分け、状態に応じて描画内容や処理を切り替えています。  
これにより、ゲーム全体の流れをJavaScript側で管理しやすくしています。

### 2. フロントエンドとバックエンドの連携

スコアやレートは画面上だけで完結させず、DjangoのViewとModelを通して保存・取得しています。  
ゲーム処理とデータ管理を分離することで、Webアプリケーションとして拡張しやすい構成を意識しました。

### 3. 継続プレイを意識したレート機能

勝敗によってレートが変化する仕組みを入れることで、単発のタイピング練習ではなく、成績の変化を楽しめる設計にしています。  
ユーザーが「もう一度プレイしたい」と感じやすい要素を加えました。

### 4. Canvasを使ったゲームらしい表現

HTML要素だけではなくCanvas APIを使い、背景、キャラクター、スコア、結果表示などを動的に描画しています。  
Webページでありながらゲームアプリに近い体験を目指しました。

## セットアップ

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 環境変数

```bash
export DJANGO_SECRET_KEY='任意の秘密鍵'
export DB_USER='PostgreSQLのユーザー名'
export DB_PASSWORD='PostgreSQLのパスワード'
```

## 起動方法

```bash
python manage.py migrate
python manage.py runserver
```

起動後、ブラウザで以下にアクセスします。

```text
http://127.0.0.1:8000/
```
