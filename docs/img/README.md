# README用画像配置ディレクトリ

GitHubのREADMEに掲載する画像は、この配下に配置します。

## 推奨ファイル

- `header/header.png` または `header/header.svg`: README上部のヘッダー画像
- `app-view/game-play.gif`: 実際のプレイ動画GIF
- `app-view/start.png`: スタート画面
- `app-view/matching.png`: マッチング画面
- `app-view/battle.png`: タイピング対戦画面
- `app-view/result.png`: 結果画面
- `system-architecture/system-architecture.png`: システム構成図
- `entity-relationship-diagram/er-diagram.png`: ER図
